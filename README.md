One image summing up the world's news of Thursday 26 November 2026:
Trump's new tariffs sink Wall Street, Russian ballistic missiles strike
Kyiv, and judges urge the Netanyahu bribery case be dropped — plus 30
more stories across 7 regions, drawn as a flat-vector broadsheet.

## Run

```sh
python3 main.py   # writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png)
```

`main.py` is standard library only; it copies the drawn `entry.png`
(1024×1024, under 1 MiB) to the output directory. Both runs write
identical bytes.
